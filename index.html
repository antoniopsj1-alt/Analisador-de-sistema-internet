⬇️ Baixar para usar offline

O pacote traz analisador_sistema.html + sw.js + um LEIA-ME. O teste do aparelho funciona sem internet; o teste de internet e a IA precisam de conexão.

📱 Instalar no celular ou tablet

Opção A — instalar como aplicativo (recomendada)

  1. Abra este site no Chrome, com internet.
  2. Toque no menu ⋮ → Instalar app ou Adicionar à tela inicial.
  3. Abra o ícone uma vez com internet para guardar tudo. Depois abre sem internet.

Opção B — usar o arquivo baixado

  1. Baixe o .zip, abra o app Arquivos, toque no .zip e escolha Extrair.
  2. Abra a pasta e toque em analisador_sistema.html, escolhendo o Chrome.
  3. O teste do aparelho funciona sem internet. O sw.js só age quando o site é aberto por endereço (https ou localhost), não por arquivo.

💻 Instalar no computador

Jeito simples

  1. Extraia o .zip em uma pasta.
  2. Dê duplo clique em analisador_sistema.html (abre no navegador).

Jeito completo (offline como aplicativo)

  1. Abra o terminal na pasta e rode python -m http.server 8080 (ou use o Live Server do VS Code).
  2. Acesse http://localhost:8080/analisador_sistema.html com internet, uma vez.
  3. No Chrome/Edge, clique no ícone de instalar na barra de endereço. Depois funciona offline com o servidor ligado.
  4. Para colocar outros apps na mesma porta, ponha os .html na pasta e siga os comentários do sw.js.

Dica: use Chrome ou Edge atualizados. Limpar os dados do navegador apaga o modo offline.
